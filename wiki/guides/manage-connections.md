# 连接管理与租期断开

[文档索引](../README.md) · [English README](../../README.md) · [中文 README](../../README.zh-CN.md)

控制台“连接管理”位于“调用日志”上方。它观察内存中的业务租期，查询不会启动下游服务。
普通用户只能查看、断开自己的租期；管理员可筛选全部业务租期并断开他人连接。
内部维护租期不进入该列表。匿名租期仅管理员可见，匿名身份键和会话 ID 不返回。

## 查看与筛选

每行展示租期 ID、用户/令牌名称、类型、心跳、到期时间、创建时间和全部引用实例。
一条租期可以使用多个 MCP；没有引用时显示“无绑定 / 未启动”。
retention 表示 HTTP 会话或调用方的保留租期，不代表独立 Agent 数量。

支持通用搜索、用户（管理员）、当前有引用的 MCP、类型、状态、心跳范围和排序。
MCP 下拉以当前用户有权查看的业务租期去重，不包含其他用户的引用。
详情 JSON 使用安全字段清单，不包含连接配置、凭据或原始错误；共享明细只列有权查看的租期。
调用日志当前无法精确归属到一条租期，因此不作为该租期的最近调用展示。

状态依次为已到期、调用中、即将到期（15 秒内）、空闲。
“本租期调用”只统计该租期实际执行的操作；实例调用数包含共享实例的整体负载。
无心跳到期时间不等于连接永久保留，空闲策略仍可能回收实例。

## 断开

单条和批量操作均须确认；管理员操作会提示他人租期。可以清理尚未回收的过期租期。
结果逐条报告许可释放、会话清理以及每个实例的实际状态：

| 结果 | 含义 |
|---|---|
| 已停止 | 实例已关闭 |
| 等待调用排空 | 已无引用，正在等待已执行的调用结束 |
| 仍有共享引用 | 其他租期继续使用同一实例 |
| 常驻保留 | eager 共享/用户实例遵循常驻策略 |

断开不是强制终止服务，也不撤销 Token。已发送的操作可能继续完成，不能假定副作用已取消。
客户端之后可以重新初始化会话或创建租期。需要阻止后续访问时使用令牌/权限管理；
需要强制停止实例时使用服务管理。参见[服务管理](manage-services.md)与[生命周期](../concepts/runtime-and-lifecycle.md)。

会话关闭或审计失败会报告部分失败，界面不会自动重试断开。先检查实际状态再决定后续操作。
页面每 5 秒刷新，可暂停或手动刷新；标签页隐藏时不请求，离开页面后停止轮询。
刷新保留筛选、页码和仍存活的跨页选择，并清除已消失的租期选择。
快照分页并非数据库事务：翻页期间租期可能到期或变化。

## 管理 API

四个端点均使用控制台登录会话；写请求需要现有 CSRF 头。

| 方法 | 路径 |
|---|---|
| GET | /api/v1/leases |
| GET | /api/v1/leases/{lease_id} |
| POST | /api/v1/leases/{lease_id}/disconnect |
| POST | /api/v1/leases/batch |

列表参数：q、user_id、mcp_id、kind、status、sort、touched_from/touched_to、
page（>=1）、page_size（1–200，默认20）。时间范围使用带时区 ISO 时间。
sort 为 touched_desc、created_desc、ttl_asc、in_flight_desc。
批量请求为 {"lease_ids":["<lease-id>"]}，每批1–200条，重复ID只执行一次；
不存在的租期幂等返回 already_released。内部维护租期禁止断开。
列表与详情可见范围均由后端强制执行；批量操作每项重新验证权限并独立报告结果。
