# 连接管理与租期断开

[文档索引](../README.md) · [English README](../../README.md) · [中文 README](../../README.zh-CN.md)

控制台“连接管理”位于“调用日志”上方。它观察内存中的业务租期，查询不会启动下游服务。
普通用户只能查看、断开自己的租期；管理员可筛选全部业务租期并断开他人连接。
内部维护租期不进入该列表。匿名租期仅管理员可见，匿名身份键和会话 ID 不返回。

## 查看与筛选

每行展示租期 ID、用户/令牌名称、类型、心跳、到期时间、创建时间和全部引用实例。
一条租期可以使用多个 MCP；没有引用时显示“无绑定 / 未启动”。实例单元格 1～2 项按内容自然增高，3 项及以上封顶三项的紧凑高度，超过三项可在单元格内上下滚动。
retention 表示 HTTP 会话或调用方的保留租期，不代表独立 Agent 数量。

支持通用搜索、用户（管理员）、当前有引用的 MCP、类型、状态、心跳范围和排序。
MCP 下拉以当前用户有权查看的业务租期去重，不包含其他用户的引用。
详情 JSON 使用安全字段清单，不包含连接配置、凭据或原始错误；共享明细只列有权查看的租期。
调用历史直接取自内存租期的业务派发计数和时间，不从全局日志推断归属，也不会混入共享实例上其他租期的调用。

状态依次为已到期、调用中、即将到期（15 秒内）、空闲。
“调用中”包含正在执行及等待派发的业务请求；“当前执行”是瞬时值，快速调用可能在两次五秒刷新之间结束。
“等待派发”包含容量排队、实例启动及实例调用队列中的请求。
“累计下游调用”统计本租期已派发的下游业务操作次数，包含失败尝试；权限拒绝和派发前取消不计入，
目录搜索、维护发现及专用心跳也不计入。“最近调用”是最后一次业务派发的时间。
这些历史字段随租期释放或网关重启而重置；空闲且当前执行为0不表示此前没有调用。
实例调用数包含共享实例的整体负载。
“心跳时间”是最近显式心跳或实际业务调用时间，首次调用前使用租期创建时间。
“心跳结束时间”是该时间加当前连接有效期；刷新不改变时间，修改配置后下次快照使用新有效期。
有效期为 0 时显示“不过期”。Bridge 另显示失联判定时间及已缺失心跳次数；关闭检测时显示“Bridge 心跳检测已禁用”。

## 三项独立策略

系统设置的“运行与日志”提供：

| 设置 | 默认值 | 作用 |
|---|---|---|
| 默认空闲回收时间 | 86400 秒 | 按最后业务调用时间回收 lazy 实例，不看引用数；0 关闭空闲回收 |
| 默认连接有效期 | 43200 秒 | 统一管理 agent、bridge、retention 的无心跳/调用租期；0 关闭到期释放 |
| Bridge 默认心跳间隔 | 90 秒 | 0 禁用 Bridge 心跳失联检测；1～86400 秒设置专用心跳间隔 |
| Bridge 失联判定次数 | 3 次 | 启用检测时，连续缺失此数量的心跳间隔即断开，范围 1～100 |

Bridge 是将 MMG 以 stdio 模式接入客户端的桥接程序，默认在最近专用心跳后约 270 秒判定失联。收到心跳即清零缺失次数；
业务调用延长租期有效期，不替代 Bridge 专用心跳。连接有效期为 0 只关闭租期到期释放；Bridge 心跳间隔为 0 才关闭失联检测。
关闭失联检测时，Bridge 仍每 90 秒续期并同步配置，连接有效期继续独立生效。
任一已启用的到期条件满足都会释放 Bridge 租期及关联会话；执行中或已进入队列的业务调用受保护，
清理可能延至调用结束及下一次维护检查。

设置保存后持久化，租期有效期立即按当前设置计算。
新 Bridge 采用当前心跳配置。设为 0 立即关闭已有租期的失联检测；重新开启时，已有 Bridge 先沿用原续期间隔的判定窗口，
下次成功心跳时同步新的间隔和判定次数，避免误断仍按旧间隔等待的客户端。重新开启后，已断联的租期仍会被清理。客户端可在下一次新请求时重连，已发送请求不会自动重放。

显式心跳不刷新实例的业务空闲计时。即使租期不过期，lazy 实例仍可被空闲回收，后续调用重新启动。
eager 实例不因租期归零、空闲超时或容量压力自动停止，包含会话隔离实例；
手动停止、服务禁用、撤权和凭据失效仍按原安全规则处理。

## 断开

单条和批量操作均须确认；管理员操作会提示他人租期。可以清理尚未回收的过期租期。
结果逐条报告许可释放、会话清理以及每个实例的实际状态：

| 结果 | 含义 |
|---|---|
| 已停止 | 实例已关闭 |
| 等待调用排空 | 已无引用，正在等待已执行的调用结束 |
| 仍有共享引用 | 其他租期继续使用同一实例 |
| 常驻保留 | eager 实例遵循常驻策略，包含会话隔离 |

断开不是强制终止服务，也不撤销 Token。已发送的操作可能继续完成，不能假定副作用已取消。
客户端之后可以重新初始化会话或创建租期。需要阻止后续访问时使用令牌/权限管理；
需要强制停止实例时使用服务管理。参见[服务管理](manage-services.md)与[生命周期](../concepts/runtime-and-lifecycle.md)。

会话关闭或审计失败会报告部分失败，界面不会自动重试断开。先检查实际状态再决定后续操作。
页面每 5 秒刷新，可暂停或手动刷新；标签页隐藏时不请求，离开页面后停止轮询。
刷新保留筛选、页码和仍存活的跨页选择，并清除已消失的租期选择。
快照分页并非数据库事务：翻页期间租期可能到期或变化。

## 管理 API

四个端点均使用控制台登录会话；写请求需要现有 CSRF 头。

| 方法 | 路径 |
|---|---|
| GET | /api/v1/leases |
| GET | /api/v1/leases/{lease_id} |
| POST | /api/v1/leases/{lease_id}/disconnect |
| POST | /api/v1/leases/batch |

列表参数：q、user_id、mcp_id、kind、status、sort、touched_from/touched_to、
page（>=1）、page_size（1–200，默认20）。时间范围使用带时区 ISO 时间。
sort 为 touched_desc、created_desc、ttl_asc、in_flight_desc。
批量请求为 {"lease_ids":["<lease-id>"]}，每批1–200条，重复ID只执行一次；
不存在的租期幂等返回 already_released。内部维护租期禁止断开。
列表与详情可见范围均由后端强制执行；批量操作每项重新验证权限并独立报告结果。
