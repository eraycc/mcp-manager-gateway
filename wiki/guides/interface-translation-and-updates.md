# 控制台外观、翻译与版本提醒

MMG 的控制台把外观、网页翻译和版本检测拆成独立功能。关闭翻译不会影响 MCP 管理、调用或审计；PyPI 暂时不可访问时也不会阻止登录和使用网关。

## 顶部菜单

登录后，页面右上角最多提供三个图标菜单：

- **语言**：仅在管理员启用全局翻译后显示，用于选择当前浏览器的目标语言；选择保存在浏览器中。
- **显示模式**：可选择浅色、深色或跟随系统。选择保存在当前浏览器中。
- **账户**：显示用户名、角色和已配置的邮箱，并提供个人资料、管理员系统设置和退出登录入口。

侧边栏中的 “MCP 审批” 与 “调用日志” 使用不同图标；“系统设置”使用清晰的调节图标，并在发现可用更新时显示提醒点。

## 启用网页翻译

管理员进入 **系统设置 → 翻译设置**，打开“启用全局网页翻译”，再选择网页原始语言与服务通道。目标语言只从右上角语言菜单选择，不在系统设置中维护第二份默认值。开启并保存后会立即按浏览器上次选择的目标语言执行翻译；关闭并保存后会停止动态翻译、恢复原始语言并隐藏语言菜单。

网页翻译由 translate.js 在浏览器内驱动。只有启用翻译后才会加载外部脚本并调用所选翻译服务。页面文字可能发送给第三方服务，因此包含敏感业务内容的部署应优先使用经过审核的私有翻译服务，或保持该功能关闭。

支持的通道包括：

- **client.edge**：默认选择，适合一般网页翻译；
- **translate.service**：公共服务通道；
- **giteeAI**：大模型翻译通道；
- **自定义私有 translate.service**：填写受信任的 HTTP(S) 服务地址。

SSE 流式翻译只对自定义私有服务开放。如果当前 translate.js 版本没有提供 SSE API，控制台会给出提示并自动回退到普通请求，不影响其他功能。

## 翻译规则与高级选项

管理员可以进一步配置：

- 按 class、id、HTML 标签或文字忽略翻译；
- 使用“原文 = 译文”形式维护自定义术语；
- 允许 URL 参数控制目标语言，并自定义参数名；
- 监控动态渲染内容；
- 整页翻译、翻译本地语种文本和任务排队；
- 导入或导出 JSON 配置；
- 清除浏览器中名称以 `hash_` 开头的翻译缓存，并显示实际清理数量；
- 恢复默认配置。

导入只会把内容载入表单；确认无误并点击“保存设置”后才会生效。重置同样需要保存。

## 版本检测与升级

“设置 → 关于”中的“自动检测更新”默认开启。开启时，管理员登录控制台后，MMG 会通过 PyPI 的项目元数据比较当前版本和最新版本；关闭时不会自动访问 PyPI，但仍可点击“检查更新”执行一次手动检测。检测结果与忽略选择按用户保存：

- 检测结果同时保存在服务端用户状态和浏览器缓存中，进入“关于”页时可以立即显示上次结果；
- 自动检测结果默认缓存 7 天，缓存过期或本地安装版本发生变化时重新请求 PyPI；
- 首次自动发现新版本时弹窗提示版本号；
- 有新版本时，“系统设置”和“关于”标签会显示提醒点；
- “关于”页显示当前版本、最新版本、PyPI 和 GitHub Releases 链接；
- 可以开启或关闭自动检测，并保存为系统设置；
- 无论自动检测是否关闭，都可以手动重新检查；
- 可以忽略当前发现的版本；
- 已忽略的版本不会重复提醒，只有出现更高版本时才会再次提醒；
- PyPI 暂时不可用时只显示检测错误，不影响网关功能。

“关于”页使用红色状态提示可用更新，使用绿色状态提示当前已是最新版本；自动检测卡片与版本信息之间保留独立间距。

## 登录会话批量管理

个人资料中的“登录会话”支持“撤销全部”和“删除全部”。两个操作都只处理当前用户除当前登录会话以外的其他会话：撤销会使其他设备立即需要重新登录，删除还会永久移除对应会话记录。当前会话不会被批量操作影响。

提醒只负责发现版本，不会自动修改当前安装。请按安装方式升级：

~~~console
# uv tool
uv tool upgrade mcp-manager-gateway

# pip 虚拟环境
pip install --upgrade mcp-manager-gateway
~~~

源码或容器部署应通过对应的源码更新或镜像重建流程升级。升级前请参阅[部署与升级](../operations/deployment-and-upgrades.md)并备份数据。
