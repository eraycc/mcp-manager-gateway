# 运行时与生命周期

## 三个不同概念

- **Token**：认证主体及权限范围，不等于一个 Agent；
- **租约**：某个 Agent 连接对运行时资源的引用；
- **实例**：实际的下游进程或网络连接。

一个 Token 可以创建多个租约，一个 MCP 也可以按用户或会话拥有多个实例。

## 调用流程

1. 鉴权并检查 Token 与用户范围；
2. 校验工具名称和 arguments；
3. 绑定租约及实例隔离键；
4. 复用就绪实例，或加入唯一启动任务；
5. 派发前再次检查权限和配置版本；
6. 执行并保留 MCP 的结构化结果、文本、图像、音频或错误；
7. 更新执行计数和业务活动时间；
8. 在引用释放或达到空闲策略时回收。

同一隔离范围的并发首次调用只创建一个启动任务。某个等待者取消不应破坏其他等待者共用的启动过程。

## lazy、eager 与 disabled

- `lazy`：真实调用时启动，最后引用释放或空闲超时后关闭；
- `eager`：服务启动时预热可共享实例；
- `disabled`：拒绝新业务调用并从可用目录移除。

`mode` 不等于实时 `status`。一个 lazy 服务在没有实例时可以是 `stopped`，但仍然可用并会在调用时启动。

## 租约与回收

stdio 桥接维护独立租约，定期心跳，正常退出时主动释放。失联超过宽限后，网关释放引用。

HTTP 客户端若支持会话 DELETE，可显式释放；无法报告退出的客户端使用保留租约。

空闲回收依据业务调用时间，不依据心跳或目录刷新。执行中的调用不会被空闲清理中断。回收实例不等于删除 Agent 身份，后续调用可以创建新实例。

## 权限变化

每次目录读取和调用都检查当前权限，不能只在连接建立时检查。

撤权后：

- 新调用立即拒绝；
- 排队调用在派发前再次拒绝；
- 已发送到下游的调用只能尽力取消；
- 已经发生的副作用不能虚构回滚。

如果请求发送后连接丢失，结果标记为 `outcome_unknown`。网关和 Agent都不应自动重放这类调用。

## 配置换代

修改连接、认证或工具限制会产生新的配置版本。新请求等待切换，旧实例排空后关闭。实例 generation 防止迟到的旧关闭回调误删新实例。

## 能力缓存

发现成功时，MMG 完整写入新快照后再切换索引。发现失败时可以保留最后一次成功快照，并明确标注刷新错误。

诊断、刷新和用户调用共享同一个运行时，刷新任务释放自己的引用时不能关闭 Agent 正在使用的实例。
